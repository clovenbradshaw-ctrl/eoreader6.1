# eoreader6.1

The kernel of [`eoreader6`](https://github.com/clovenbradshaw-ctrl/eoreader6),
rebuilt on its own terms: not a JavaScript port, but grounded directly in EO's
own primitive — difference against a ground you rebuild — and written in
EO's own notation rather than hosted in Rust, JavaScript, or Python syntax.

See `docs/KERNEL_REBUILD_CHECKPOINT.md` for the design checkpoint.
